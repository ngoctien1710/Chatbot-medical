RAG data layout:

- raw/: Put source .txt or .md files here.
- chroma/: Persisted vector index generated by Python RAG service.

Quick start (Python service + Node gateway):
1) Pull required Ollama models
   - ollama pull nomic-embed-text
   - ollama pull llama3.2:3b
2) Start Python RAG service on port 8001
   - See python-rag-service/README.md
3) Trigger ingest
   - POST http://127.0.0.1:8001/rag/ingest
   - or POST http://127.0.0.1:3000/rag/ingest (proxy via Node gateway)
4) Start Node gateway
   - npm start
